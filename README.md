<h1> Things!!! </h1> 

-> File metadata & descriptions (Size, Date Modified)<br>
-> Open in default app (or straight into Neovim for text files) <br>
-> Live File Previews (reads text files right in the UI as you scroll) <br>
-> Dynamic Sorting (s to cycle between Name, Size, and Date) <br>
-> Fuzzy Search & Filtering (/) <br>
-> Persistent Action History (h to toggle) & Live Corner Notifications <br>
-> Toggle hidden dotfiles (-) <br>
-> Create files/folders (n) <br>
-> Delete (d - with a safety confirmation prompt) <br>
-> Rename (r)<br>
-> Copy (c) <br>
-> Paste (v) <br>
-> Leave/Enter (Backspace, Enter) <br>
-> Move up and down (arrow keys, stupid)<br>
