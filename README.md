Learning Project and SwagCat!!!!!


TUI based project i made because i was learning Rust and wanted to challenge myself, it's still barebones but it does things!!!! 

## Things!!!
-> delete (d)
-> rename (r)
-> copy (c)
-> paste (v)
-> Leave/Enter (Backspace, Enter)
-> move up and down (arrow keys, stupid)
